# Backend Data Model

This document outlines the MongoDB Mongoose schema used to store Inquiries.

## Inquiry Schema (`server/models/Inquiry.js`)

```javascript
{
  inquiryNumber: String, // e.g., PSI-2026-000001 (Unique, generated by atomic counter)
  date: String,
  salesPerson: String,
  status: String, // 'draft' or 'submitted'

  customer: {
    companyName: String,
    contactPerson: String,
    designation: String,
    mobile: String,
    email: String,
    billingAddress: String,
    siteLocation: String,
    gstNo: String
  },

  business: {
    customerType: String,
    customerTypeOther: String,
    industryType: String,
    locationGidc: String,
    facility: String,
    facilityOther: String,
    areaSqft: Number,
    floors: Number,
    status: String,
    expectedDate: String
  },

  products: [String],
  productOther: String,

  requirement: {
    productSpecification: String,
    estimatedQuantity: String,
    currentBrand: String,
    currentPurchase: String,
    reason: String
  },

  commercial: {
    requirementValue: Number,
    expectedOrderValue: Number,
    budget: String,
    paymentTerms: String,
    decisionMakerName: String,
    decisionMakerDesignation: String,
    decisionRole: String,
    purchaseDecisionBy: String,
    competitors: String
  },

  visit: {
    visitType: String,
    personMet: String,
    requirementDiscussed: String,
    photos: String,
    opportunity: String
  },

  followUp: {
    nextAction: [String],
    nextVisitType: String,
    quotationDate: String,
    followUpDate: String,
    nextActionCommitment: String
  },

  remarks: String,

  photos: [{
    fileName: String,
    sizeKB: Number,
    previewUrl: String
  }],

  submissionMeta: {
    confirmedBy: String,
    confirmedAt: Date
  }
}
```

## Indexes
To optimize dashboard queries, the following fields are indexed:
- `inquiryNumber`
- `customer.companyName`
- `salesPerson`
- `visit.opportunity`
- `followUp.followUpDate`
- `date`
- `status`
