# Backend API Reference

Base URL: `/api/v1`

## Endpoints

### 1. Health Check
Checks if the server is running and the database is connected.
- **URL**: `/health`
- **Method**: `GET`
- **Response**:
```json
{
  "success": true,
  "data": {
    "service": "pocika-api",
    "database": "connected"
  }
}
```

### 2. Get KPI Summary
Gets dashboard statistics.
- **URL**: `/inquiries/summary`
- **Method**: `GET`
- **Response**:
```json
{
  "success": true,
  "data": {
    "total": 120,
    "today": 5,
    "hot": 15,
    "pendingFollowUps": 8
  }
}
```

### 3. Create Inquiry
Submits a new inquiry.
- **URL**: `/inquiries`
- **Method**: `POST`
- **Body**: See Data Model (Omit `inquiryNumber` as it is generated by the server)
- **Response**:
```json
{
  "success": true,
  "data": {
    "_id": "64abcdef...",
    "inquiryNumber": "PSI-2026-000001",
    "status": "submitted",
    "...": "..."
  }
}
```

### 4. List Inquiries
Retrieves a paginated list of inquiries with optional filters.
- **URL**: `/inquiries`
- **Method**: `GET`
- **Query Parameters**:
  - `page`: Page number (default: 1)
  - `limit`: Items per page (default: 10, max: 100)
  - `search`: Full text search across number, company, contact, location
  - `opportunity`: e.g. "HOT", "WARM", "COLD"
  - `status`: e.g. "submitted"
  - `sort`: "newest", "oldest", "followup"
- **Response**:
```json
{
  "success": true,
  "data": {
    "items": [...],
    "pagination": {
      "page": 1,
      "limit": 10,
      "total": 50,
      "totalPages": 5
    }
  }
}
```

### 5. Get Inquiry by ID
Retrieves a single inquiry by its MongoDB `_id` or string `inquiryNumber`.
- **URL**: `/inquiries/:id`
- **Method**: `GET`

### 6. Update Inquiry
Updates specific whitelisted fields on an inquiry.
- **URL**: `/inquiries/:id`
- **Method**: `PATCH`
- **Allowed Fields**: `visit.opportunity`, `followUp.nextAction`, `followUp.followUpDate`, `remarks`, `status`
